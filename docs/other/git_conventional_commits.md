# Git 提交书写规范

## 核心格式

```
<type>(<scope>): <subject>

<body>

<footer>
```

## 各部分说明

1. `<type>` 提交类型

标记了此次提交的类型，具体有如下分类

|类型|说明|
|:--:|:--:|
|`feat`|新增功能|
|`fix`|修复 BUG|
|`docs`|文档变更|
|`style`|代码格式调整|
|`refactor`|代码重构（不新增功能也不修复 BUG）|
|`perf`|性能优化|
|`test`|测试相关|
|`chore`|构建过程或辅助工具变动|
|`revert`|回退提交|

2. `<scope>` 影响范围（可选）

3. `<subject>` 提交主题，首字母小写、不加句号

4. `<body>` 提交的详细说明（可选）

5. `<Footer>` 关联 Issue、破坏性变更（可选）
